\# Project Conventions



\## Stack

\- Framework: Next.js (App Router)

\- Language: TypeScript

\- Styling: Tailwind CSS

\- Package manager: npm



\## Conventions

\- Use functional components with hooks, no class components.

\- Prefer server components by default; mark client components explicitly with `"use client"`.

\- File naming: kebab-case for files, PascalCase for component names.

\- Keep components small and single-purpose; colocate component-specific styles/logic.

\- All commits follow Conventional Commits (feat, fix, chore, docs, refactor, etc.).



\## Notes for AI Assistant

\- Favor readable, well-typed code over cleverness.

\- Ask before adding new dependencies.

\- When editing existing files, preserve existing formatting conventions.
